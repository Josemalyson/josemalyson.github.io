# Qual é o próximo passo?

Material de estudo, a partir do repositório [mattpocock/skills](https://github.com/mattpocock/skills) e das páginas em [aihero.dev/skills](https://www.aihero.dev/skills). Não é um projeto meu, e não é oferta de serviço.

// 27 skills promovidas + 8 em progresso · revisado contra commits até 12/11/2026 (5863806)

Cada skill tem a fonte que eu abri ao lado. Cada workflow aparece com um selo: **verificado** quando todos os passos vêm de fontes que li, **parcial** quando um passo é inferido, e **dedução** quando o caminho é meu e não consta nas fontes.

### Instalar

```text
npx skills@latest add mattpocock/skills
```

Instale o conjunto inteiro, não skills avulsas. Algumas dependem de outras (ver Regras). Depois rode `/setup-matt-pocock-skills` uma vez por repositório. Se você já rodou antes da v1.3.2 (29/10/2026), rode de novo: os templates do tracker em `docs/agents/` mudaram (fonte: [CHANGELOG 1.3.2](https://github.com/mattpocock/skills/blob/main/CHANGELOG.md)).

Codex: `codex plugin marketplace add mattpocock/skills`, depois `codex plugin add mattpocock-skills@mattpocock`. Copilot também tem plugin. Fonte secundária: SSD Nodes, 15/10/2026; confirme no README.

Selos dos workflows: **verificado** (todos os passos vêm de fontes lidas), **parcial** (um passo é inferido) e **dedução** (o caminho não consta nas fontes).

O menu Guias de bolso também tem o [guia BMAD](/guias/bmad/). Os comandos do [playbook AI-First](/playbook/ai-first/) aparecem no passo correspondente de cada fluxo.
