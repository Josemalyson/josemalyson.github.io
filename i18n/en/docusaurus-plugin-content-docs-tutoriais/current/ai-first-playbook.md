## What it is

An engineering operating system: people set intention and risk, specifications make the work verifiable, and agents execute inside explicit limits. Three layers: the change contract, the execution harness, and the control plane. The default flow is intention, spec, plan, stories, execution, verification, approval, and deploy. Agent autonomy does not replace human responsibility.
