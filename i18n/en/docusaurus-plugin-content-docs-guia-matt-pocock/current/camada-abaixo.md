# Uma camada abaixo

As skills decidem o quê e em que ordem. Estas três ferramentas, do mesmo autor (Akita, akitaonrails), ficam por baixo: memória, sandbox e custo. Não foram revisadas skill por skill nesta versão, só confirmadas como existentes.

Estas ferramentas não são do repositório do Matt Pocock. A autoria é dos projetos originais, ligados abaixo.

### ai-memory · ferramenta externa

Onde o [/handoff](/guias/matt-pocock/skills/productivity#handoff) é manual, o ai-memory captura prompts e tool calls sozinho. Quando você troca de sessão ou de agente, o próximo começa com um "onde você parou".

não verificado nesta versão [fonte original](https://github.com/akitaonrails/ai-memory)

### ai-jail · ferramenta externa

Roda o agente num sandbox do sistema: só a pasta do projeto é gravável, e rede, GPU e display ficam desligados por padrão.

não verificado nesta versão [fonte original](https://github.com/akitaonrails/ai-jail)

### ai-usagebar · ferramenta externa

Mostra quanto da cota já foi usada em cada provedor, na barra do sistema ou no terminal.

não verificado nesta versão [fonte original](https://github.com/akitaonrails/ai-usagebar)
