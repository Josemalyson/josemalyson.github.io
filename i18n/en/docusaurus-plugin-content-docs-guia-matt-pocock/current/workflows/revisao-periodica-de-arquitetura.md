# Revisão periódica de arquitetura

Quando: a cada poucos dias ou antes de um refactor grande. Fica fora da cadeia.

**Cadeia:** [`/improve-codebase-architecture`](/guias/matt-pocock/skills/engineering#improve-codebase-architecture)

**Verificado:** o improve gera relatório HTML e faz grilling sobre o candidato escolhido, e não implementa. O Matt descreve o uso como manutenção periódica que "enfileira trabalho". **Dedução:** o caminho depois da escolha até os tickets.

### Comandos no playbook AI-First

Revisão de arquitetura no playbook atualiza a spine (decisões AD-n) e, se o comportamento mudou, o PRD:

```text
/bmad-architecture
/bmad-prd
```
