# Não entendi a resposta do agente

Quando: uma mensagem do agente não fez sentido. Pode ser usado em qualquer conversa.

**Cadeia:** [`/wait-what`](/guias/matt-pocock/skills/productivity#wait-what)

**Por que existe:** o Matt diz que o problema não é o agente usar palavras difíceis, é ele usar palavras que o projeto não definiu. Por isso o wait-what usa o GLOSSARY.md.

### Comandos no playbook AI-First
