# Sessão pesada ou troca de contexto

Quando: a conversa está cheia, ou o trabalho precisa trocar de sessão, pasta ou pessoa.

**Cadeia:** [`/handoff`](/guias/matt-pocock/skills/productivity#handoff)

**Regra:** não limpe nem compacte entre to-spec e to-tickets. Rode os dois na mesma janela. Faixa boa de contexto: cerca de 150k tokens. **Fonte:** ask-matt (fronteira de fase) e notas v1.2.

### Comandos no playbook AI-First

Estado durável fica fora da janela de contexto (story status, plano, decisões, testes, deferred-work). No BMAD isso vive em `_bmad-output/`. O contexto do repositório vai no `AGENTS.md`:

```text
/bmad-project-context set up AGENTS.md
```
